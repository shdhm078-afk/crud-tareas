# Gestor de Tareas - CRUD PHP

App sencilla para gestionar tareas con PHP puro.

## Requisitos
- PHP 7.4 o superior

## Cómo ejecutar
1. Abre una terminal en la carpeta del proyecto
2. Ejecuta: php -S localhost:8000
3. Abre en el navegador: http://localhost:8000

## Funcionalidades
- Crear tareas nuevas
- Marcar tareas como completadas
- Borrar tareas
- Muestra fecha y hora de creación
- Contador de tareas totales y pendientes
